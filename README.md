# 💻 MULTIVENTAS RAFA

### Tu mejor aliado en útiles escolares, productos de aseo, desechables y cacharrería.

## 📌 Descripción del proyecto

**Multiventas Rafa** es un proyecto de desarrollo de software orientado a la creación de una tienda virtual que permita visualizar productos, consultar precios y facilitar la experiencia de compra de los clientes.

La aplicación busca ofrecer una interfaz moderna, organizada, intuitiva y accesible, que permita a los usuarios explorar las diferentes categorías de productos de manera sencilla.

Este proyecto se desarrolla como parte del proceso de formación en el programa **Tecnólogo en Análisis y Desarrollo de Software del SENA**.

## 🎯 Objetivo general

Desarrollar una aplicación web para la distribuidora Multiventas Rafa que facilite la presentación y consulta de productos mediante una interfaz digital intuitiva, moderna y organizada.

## 🎯 Objetivos específicos

- Diseñar una interfaz web atractiva y fácil de utilizar.
- Organizar los productos por categorías.
- Facilitar la consulta de productos y precios.
- Implementar funcionalidades interactivas mediante JavaScript.
- Aplicar tecnologías de desarrollo web en la construcción de la aplicación.
- Mejorar la experiencia de navegación de los usuarios.

## 🛍️ Categorías de productos

La tienda está orientada a la comercialización de productos como:

- 📚 Útiles escolares.
- 🧹 Productos de aseo.
- 🥤 Productos desechables.
- 🧺 Artículos de cacharrería.
- 🧴 Productos plásticos.

## 🛠️ Tecnologías utilizadas

| Tecnología | Descripción |
|---|---|
| HTML5 | Estructura de las páginas web. |
| Tailwind CSS | Diseño y estilos de la interfaz. |
| JavaScript | Funcionalidades e interactividad. |
| Git | Control de versiones del proyecto. |
| GitHub | Almacenamiento y administración del repositorio. |
| Visual Studio Code | Entorno de desarrollo. |

## ✨ Funcionalidades principales

- Página de inicio con información de la distribuidora.
- Menú de navegación.
- Visualización de productos.
- Organización de productos por categorías.
- Consulta de precios.
- Barra de búsqueda de productos.
- Carrito de compras.
- Diseño adaptable a diferentes tamaños de pantalla.
- Interfaces de inicio de sesión y registro de usuarios.
